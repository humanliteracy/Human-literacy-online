# ONE PLACE — whole-life assistance founder preview

**Status: DRAFT / UNPUBLISHED / NOT FOR SALE**

The existing Human Literacy site remains published from `main`. This draft branch proposes a new broad assistance section at `one-place/index.html` inside the **same repository** without changing the lessons or Life Simulator. Existing draft PR #5 must stay untouched.

## What exists in this first repository preview

- 18 life areas and 72 navigable cards: 36 free-help starting points, 18 planned digital products, 18 planned assisted services.
- Search, category filters, type filters, working detail views, sample export, and six browser-based product demonstrations.
- Free entries link to established external resources; these are not endorsements or guarantees.
- All paid products and services show an interactive **demo**, **not a checkout**. No offerings are for sale or bookable.
- The prototype does not use accounts, external APIs, analytics, persistent storage, payments, or a backend.
- The public Human Literacy homepage, lessons, artwork and PR #5 should not be altered or deployed as part of reviewing this concept.

## How to review

1. In GitHub, switch to branch `concept/one-place-whole-life-prototype` and view `one-place/index.html`; GitHub's code preview does not run the page. Download the HTML file to see it offline (it is a single file).
2. Or download the separately provided founder review ZIP from the ChatGPT conversation and open `START_HERE_One_Place_Founder_Preview.html` locally. That package contains a more polished modular source implementation.
3. Browse all 18 category filters, all 3 offering types, and search terms like debt, caregiver, pricing, jobs.
4. Open free-help links (external providers), paid-product previews and service concepts. Confirm nothing falsely promises payment or delivery.
5. Try the six product demonstrations. Check the sample .txt exports.
6. Manually test Chromebook desktop and narrow/mobile layouts, keyboard Tab/Enter/Escape, screen-reader announcements, and 200% zoom. A complete automated accessibility/visual test is **not yet confirmed**.
