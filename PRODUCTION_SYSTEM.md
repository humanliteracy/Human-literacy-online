# Human Literacy — Production Operating System
Version: 1.0 · 2026-10-25

## Mission
Provide free, anonymous, practical, evidence-informed education for humanity. Improve health, understanding, relationships, daily living, and access to trustworthy help. Maintain accessibility, accountability, and a clear distinction between evidence and aspiration.

## Production lanes
1. **Interactive curriculum:** reusable five-stage learning model; concrete scenarios, independent practice, review, and real-world application.
2. **Video:** reusable silent, captioned cinematic templates; selectively incorporate short live-action scenes when they improve learning.
3. **Guides and downloads:** accessible HTML first, then printable PDFs with sources and review dates.
4. **Verified resources:** local and global directories with geographic scope, eligibility, source, and last-reviewed date.
5. **Platform:** navigation, discovery, performance, accessibility, privacy-conscious metrics, and feedback.
6. **Quality and impact:** technical checks, editorial review, usability testing, correction process, and learning outcomes.

## Definition of done
A resource is only 'published' when:
- Learning objective and intended audience are explicit.
- Accuracy and safety claims have been reviewed, with source dates where applicable.
- Plain language and accessible navigation/captions are present.
- Content has been checked for harmful stereotyping, unsupported promises, and misleading framing.
- Links, media, keyboard navigation, and mobile layout are tested.
- A reviewer records pass/fail and fixes any blockers.
- The final public URL is confirmed working.

## Batch workflow
Idea backlog -> priority and objective -> draft -> evidence check -> media generation -> assembly -> automated validation -> manual review -> publish -> measure -> revise.

## First sprint (10 working days)
- Establish repository quality checks and record current warnings.
- Audit all 10 interactive lessons for navigation, state, feedback, and quiz scoring.
- Extract a reusable lesson schema and rendering template without changing approved pedagogy.
- Produce one batch of five new lesson specifications and one batch of five video scripts.
- Build a production register tracking owner, status, sources, review, URL, and time spent.
- Publish only work that passes the definition of done.

## Metrics
Weekly: finished approved resources, production hours per resource, QA failures caught before publishing, unresolved bugs, cost per published video, broken links, learner feedback, and return visits when measurable.
Quarterly: completion and comprehension measures, accessible usage, partner adoption, revenue/expense transparency, and correction turnaround.

## Financial discipline
Buy services to remove measured bottlenecks. Separate actual expenses and earnings from projections. Core education stays free; affiliate relationships are disclosed. Rewards and donations require funded, published rules.

## Growth
2027: repeatable library and first pilots.
2028: validated learning pathways and contributors.
2031: scalable partnerships and multilingual expansion.
2036: global education and resource network.
2046: enduring, independently governed public-benefit institution.
These are aspirations, not forecasts.
