# Human Literacy — Competitive Intelligence, Platform Economics & Execution
**Research baseline: October 25, 2026.** Detailed companion to the first [landscape audit](competitive-landscape-2026-10-25.md). Public pricing and third-party traffic change; verify before contracts.

## Executive assessment
Human Literacy's opportunity is to integrate **Explore → Understand → Express (unscored) → Simulate → Reflect → Rehearse → Act in real life → Find verified help** into an accessible, free foundational site. It would be incorrect to claim there are no comparable products. AI roleplay, learning content, branching stories, emotional-skills frameworks, gamification, and local resource navigation already have capable providers. Better integration and demonstrated learner outcomes—not a boast about uniqueness—are the competitive thesis.

The founder's usability tests found the voice-duration and pause meter unhelpful but found roleplay, unrestricted speaking, consequences and replay engaging. That justifies replacing the meter with **local record/listen/rehearse** functionality, but is *one-person feedback*, not proof of therapeutic effects or general user preference. A [154-study review of anger-regulation techniques](https://pubmed.ncbi.nlm.nih.gov/38518585/) argues against assuming that venting reduces anger.

## Measurement rules
- **Monthly visits** are estimated visits to the *website*, not unique humans, active accounts or mobile-app users. Use a single vendor/month for strict comparisons.
- **Company earnings** mean audited or filed financial outcomes. A private firm's venture funding is **not** profit or revenue. A web-estimator's visits are **not** actual internal analytics.
- **Price** must distinguish an individual using an app from a developer embedding an API into Human Literacy for anonymous visitors. Subscription access does not automatically provide redistribution rights.
- If an amount cannot be independently verified, report **not publicly verified**, never $0.

## What Human Literacy should build, buy, link or test
**Build now:** the learner journey, accessible site, privacy-consent controls, roleplay engine, replay, life-task outcomes, evaluation rubric, tests and review workflow. Preserve all ten approved lessons and the illustrative neutral manager.

**Experiment with low-cost tools:** Twine for nonlinear authoring and open-source H5P for interactive media. H5P software and H5P.com hosting are not the same license/cost proposition; check per-component licenses.

**Paid API, not individual subscription:** Tavus for real-time character video if it improves actual learning; Inworld or similar for speech components; text-conversation models with server-side credentials and per-session budget caps. Do not expose keys on public GitHub Pages.

**Partner/link:** CASEL, OpenStax, GCFGlobal, 211 and other trustworthy domain authorities. Do not copy copyrighted proprietary content wholesale. Maintain attribution and source review dates.

## Budget mechanics
A 5-minute conversational-avatar session multiplied by 1,000 visitors means 5,000 streamed minutes/month. At **hypothetical** all-in media costs of $0.10, $0.35 and $0.75/minute, that is respectively **$500, $1,750 and $3,750 monthly** *before* development, hosting, safety moderation, LLM, staff and customer care. This illustration is **not a supplier quotation**. Validate exact contracts, free minutes, overages, concurrency, data retention and age requirements.

## GitHub Pages constraint
GitHub allows static educational content, but [Pages hosting restrictions](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits) forbid treating Pages as free hosting for an online business primarily facilitating transactions or commercial SaaS. Keep the present static education foundation; procure an appropriately hosted secure backend when turning roleplay into a public AI service or operating a significant marketplace.

## Work and Codex: maximum practical use
Based on [OpenAI's October 2026 Work/Codex documentation](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex):
- **Chat:** strategy, founder review, short decisions, instructional design.
- **Work:** extended research, working across apps, browser investigation, reports, handoffs, verified artifacts.
- **Codex:** branch-based GitHub features, code reviews, linting, tests, CI, fixes, performance optimization.
- The user's previously stated $20 monthly fee matches Plus's listed price; do **not** infer account access from a casual plan label. Check Work/Codex availability in the app before upgrading.
- Chat subscription fees do not include public AI API use; separate billing and limits apply.
- Product process: founder direction -> Work research/spec -> Codex branch/implementation/tests -> founder reviews one finished capability -> deploy -> measure -> maintain.
- Suggested Codex assignment: *'On humanliteracy/Human-literacy-online, add browser-based regression tests for all ten interactive lessons and the Life Simulator. Fix defects without altering approved curriculum. Implement Express -> Listen Back -> Rehearse with explicit microphone consent and on-device audio playback. Submit a tested branch for review.'*

## 90-day prioritized delivery
1. **Days 1-15:** replace useless volume meter with optional real audio recording, playback, deletion and rehearsal; code tests; audit privacy.
2. **Days 16-30:** prototype secure AI text roleplay in a private branch; measure response quality and average cost per learner session.
3. **Days 31-60:** introduce reusable experience schema, five new scenarios, launch a verified content-source checklist and improve accessibility.
4. **Days 61-90:** A/B test voice-only and live-action avatar experiences against neutral illustrated simulation, using learner comprehension, usability, errors, cost and return visits.

## Honest unknowns & next research
Vendor profits, private operating costs, unit economics and the exact number of active users often are not released. The next round should request vendor security dossiers, sandbox limits, accessibility statements, embedding rights, age policies, privacy retention, compute limits and scalable published unit pricing.

**Conclusion:** We don't have to invent every component. The major competitive advantage to pursue is a trustworthy, enjoyable, accessible and age-spanning system that translates exploration into useful real-world action. Popularity without learner benefit would be a poor success metric.

**Evidence quality:** Public SEC figures = filed; nonprofit annual reports and 990s = public organizational reporting; Semrush = modeled web visits; vendor pricing = marketing offer/current checkout may vary; private funding = investment raised, not income; strategic recommendations = our judgment.
