## Covered behavior

- All ten lessons: library links, mobile layout, practice feedback, response-comparison gates, quiz submission, completion, restart, and return home. Lesson 01 additionally verifies a known 3-of-3 quiz result. Both approved lesson videos play.
- Optional practice: closed initially, microphone consent unchecked, no permission request just from opening or checking consent, and writing usable without recording.
- Actual browser recording and playback using Chromium's synthetic microphone; playback starts only when chosen. Audio deletion revokes its object URL and releases media tracks. No uploads or external requests occur in the recording check.
- Withdrawal of consent, closing the panel, page hiding, clearing practice, pagehide cleanup, real navigation, and return navigation. Private writing is cleared on navigation; microphone tracks stop.
- Denied permission, missing recorder support, permission responses arriving after cancellation, deletion during finalization, overlapping-start prevention, and the 90-second recording limit.
- First expression and reflection stay separate from rehearsal. Moving a draft fills the roleplay reply without submitting; sending remains a second explicit action. Moving a draft after completion starts a new conversation.
- Default roleplay produces no numerical score or score details. Choosing numerical feedback produces the expected 94/100 for a known conversation; withdrawing that choice clears the score. Private expression remains ungraded.
- No JavaScript exceptions in the interaction and lesson regression tests. The private-writing check confirms no application cookies, local storage, session storage, uploads, or external requests.

## Limits

Physical microphones, recording quality, mobile operating-system permission dialogs, Firefox, and Safari have not been tested. Some failure and lifecycle cases use controlled browser API/event simulations; actual microphone encoding/playback and real page navigation are also exercised. This is not a full accessibility audit.

GitHub Actions configuration is included, but no remote CI run, deployment, or merge has been performed. The new CI job installs Playwright's Chromium and runs the same `npm test` command on Node.js 22 and Python 3.12.
